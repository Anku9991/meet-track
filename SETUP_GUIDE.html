✅ Installation Steps

Step 1: Install Dependencies

Install Node.js from https://nodejs.org (v16 or newer)

npm install

This installs: Express, CORS, JWT, bcryptjs, validators, and security middleware

Step 2: Configure Environment

Copy the example environment file:

cp .env.example .env

Edit .env and update JWT_SECRET with a strong password (min 32 characters)

Step 3: Start the Server

For development with auto-reload:

npm run dev

Server starts at: http://localhost:3000

Step 4: Initialize Admin Account

First time setup only. Send this request:

curl -X POST http://localhost:3000/api/auth/init \
  -H "Content-Type: application/json" \
  -d '{
    "pin": "1234",
    "password": "your_secure_password_min_8_chars"
  }'

✓ Copy the token from response — you'll need it for all admin operations

🔗 Frontend-Backend Integration

Admin Portal Configuration

Edit meeting-admin-v2.html to add API configuration:

// Add near top of <script> section:
const API_BASE = 'http://localhost:3000/api';  // Change to your backend URL
let authToken = localStorage.getItem('auth_token');

// Modify doLogin() to use backend:
async function doLogin() {
  const pin = document.getElementById('f_pin').value;
  if (pin.length !== 4) {
    showToast('❌ PIN must be 4 digits', true);
    return;
  }
  
  try {
    const res = await fetch(`${API_BASE}/auth/login`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ pin })
    });
    
    if (!res.ok) {
      const err = await res.json();
      showToast(`❌ ${err.error}`, true);
      return;
    }
    
    const data = await res.json();
    authToken = data.token;
    localStorage.setItem('auth_token', authToken);
    
    // Now logged in
    showDashboard();
  } catch (e) {
    showToast('❌ Connection error: ' + e.message, true);
  }
}

      },
      body: JSON.stringify(meeting)
    });

    const result = await res.json();

    showToast('❌ ' + e.message, true);
  }
}

🐳 Docker Deployment

Option 1: Docker Compose (Easiest)

docker-compose up -d

This automatically:

  • Builds the Docker image
  • Starts the API container on port 3000
  • Creates data persistence volumes
  • Sets up health checks

Option 2: Manual Docker Build

docker build -t meettrack:2.0 .
docker run -d \
  --name meettrack \
  -p 3000:3000 \
  -e JWT_SECRET="your-secret" \
  -v meettrack-data:/app/data \
  meettrack:2.0

📊 API Testing

Use the following commands to test all API endpoints:

# 1. Initialize admin
curl -X POST http://localhost:3000/api/auth/init \
  -H "Content-Type: application/json" \
  -d '{"pin":"1234","password":"pass123456"}'

# 2. Login
RESP=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"pin":"1234"}')
TOKEN=$(echo $RESP | grep -o '"token":"[^"]*' | cut -d'"' -f4)

# 3. Create meeting
curl -X POST http://localhost:3000/api/meetings \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Test Meeting",
    "topic": "Testing the API",
    "date": "2024-01-20",
    "time": "10:00",
    "venue": "Room A",
    "window": 60
  }'

# 4. Get meetings
curl -X GET http://localhost:3000/api/meetings \
  -H "Authorization: Bearer $TOKEN"

# 5. Get stats
curl -X GET http://localhost:3000/api/stats \
  -H "Authorization: Bearer $TOKEN"

🆘 Troubleshooting

Problem Solution
Connection refused (localhost:3000) Server not running. Run npm run dev
"Admin not found" error Run initialization: curl -X POST http://localhost:3000/api/auth/init ...
"Invalid token" Token expired or invalid. Re-login to get new token
CORS error in browser Update CORS_ORIGIN in .env to match frontend domain
Rate limit exceeded Wait 15 minutes or reduce RATE_LIMIT_MAX_REQUESTS
Docker container won't start Check logs: docker logs meettrack

📈 Performance Optimization

For High Volume (1000+ attendees/meeting)

  1. Switch to MongoDB: Edit server.js and uncomment MongoDB section
  2. Add Redis Caching: Cache frequent queries
  3. Enable Compression: Add gzip middleware
  4. Use CDN: Serve static HTML files from CDN
  5. Load Balancing: Run multiple API instances behind nginx
